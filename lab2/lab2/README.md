# Лабораторна робота №2

## Тема

Побудова вкладеної навігації та оптимізація відображення великих списків у React Native із використанням компонентів FlatList та SectionList.

## Мета роботи

Метою роботи є створення мобільного застосунку на React Native / Expo з вкладеною навігацією Drawer Navigator та Stack Navigator, використанням FlatList для великого списку новин, SectionList для згрупованих контактів, передачею параметрів між екранами та базовою оптимізацією списків через віртуалізацію.

## Запуск проєкту

```bash
npm install
npm start
```

## Контрольні запитання та відповіді

1. Чим відрізняється FlatList від ScrollView?

ScrollView рендерить усі елементи одразу, тому він більше підходить для невеликих обсягів даних. FlatList використовує віртуалізацію та підходить для великих списків.

2. Що таке віртуалізація списків?

Віртуалізація списків - це механізм, за якого відображаються тільки видимі елементи списку та невеликий буфер навколо них.

3. Як здійснюється передача параметрів між екранами?

Параметри передаються через `navigation.navigate('ScreenName', params)`, а на наступному екрані отримуються через `route.params`.

4. Що таке вкладена навігація?

Вкладена навігація - це підхід, коли один навігатор знаходиться всередині іншого, наприклад Drawer Navigator містить Stack Navigator.

5. У яких випадках застосовується SectionList?

SectionList застосовується, коли дані потрібно відображати групами або секціями, наприклад контакти за групами, товари за категоріями або повідомлення за датами.
